## Workspace Navigation

| Action                        | Keybinding                                                         |
| ----------------------------- | ------------------------------------------------------------------ |
| Switch to workspace 1         | `Super+Home`                                                       |
| Switch to workspace last      | `Super+End`                                                        |
| Switch workspace left         | `Super+Page_Up` · `Super+Alt+Left` · `Ctrl+Alt+Left`              |
| Switch workspace right        | `Super+Page_Down` · `Super+Alt+Right` · `Ctrl+Alt+Right`          |
| Switch workspace up           | `Ctrl+Alt+Up`                                                      |
| Switch workspace down         | `Ctrl+Alt+Down`                                                    |

## Move Window to Workspace

| Action                              | Keybinding                                                                   |
| ----------------------------------- | ---------------------------------------------------------------------------- |
| Move window to workspace 1          | `Super+Shift+Home`                                                           |
| Move window to workspace last       | `Super+Shift+End`                                                            |
| Move window to workspace left       | `Super+Shift+Page_Up` · `Super+Shift+Alt+Left` · `Ctrl+Shift+Alt+Left`      |
| Move window to workspace right      | `Super+Shift+Page_Down` · `Super+Shift+Alt+Right` · `Ctrl+Shift+Alt+Right`  |
| Move window to workspace up         | `Ctrl+Shift+Alt+Up`                                                          |
| Move window to workspace down       | `Ctrl+Shift+Alt+Down`                                                        |
